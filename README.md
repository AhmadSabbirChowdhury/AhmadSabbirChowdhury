### About me

I'm an **AI Research Analyst** at **Nova Scotia Health** and a recent **MSc in Computer Science** graduate from **Acadia University** (Wolfville, NS, Canada). My work sits at the intersection of applied machine learning research, data science, and healthcare AI — building systems that turn complex data into actionable clinical insight.

I've published research at **IEEE BIBM 2024**, built CNN-based diagnostic tools for medical imaging, developed automated ML pipelines for radiotherapy research, and worked on sleep analysis using wearable sensor data. I'm passionate about making AI practical, explainable, and useful in real-world settings.

---

### What I'm working on

🔬 **Lung SBRT Radiotherapy Research** — Building automated data extraction and ML pipelines using C# ESAPI scripting for the Varian Eclipse treatment planning system

😴 **Sleep Analysis with Wearables** — REM sleep classification and sleep onset detection using Apple Watch data

🧠 **Diabetic Retinopathy Detection** — [Open-sourced](https://github.com/AhmadSabbirChowdhury/Diabetic-Retinopathy-Detection-CNN) my IEEE BIBM 2024 published research: custom CNN achieving 95% binary classification accuracy on fundus images
